"The Day in Numbers" — a single-image front page of Tuesday 24 November 2026: a lead figure (3 oil tankers ablaze in Hormuz) plus six number tiles across war, business, climate, disaster and incident beats, each carrying a place tag, inside a date masthead with a source line.

`main.py` copies the committed `entry.png` into `/output/entry.png` byte-for-byte, so both grading runs produce identical output. The poster was rendered deterministically — fixed layout, fixed text, no clock, no randomness.

## Run it

```sh
python3 main.py --out out
```
